# 🎓 LearnIt - Fun Educational Game

Learn English & Math, but it's actually fun! LearnIt is an engaging educational game (edtech) that specializes in **understanding over speed**, with just the right amount of repetition to help kids learn effectively.

## ✨ Features

### Student Mode
- 📚 **Multiple Math Topics**: Fractions, Addition, Subtraction, Multiplication, and Division
- 🎨 **Visual Learning Aids**: Interactive visual representations to help understand concepts
- 💪 **Positive Reinforcement**: Encouraging feedback messages that build confidence
- 💡 **Hint System**: Get helpful hints when stuck on a problem
- 📖 **Detailed Explanations**: Understand *why* an answer is correct, not just what it is
- 📊 **Progress Tracking**: See your progress as you complete questions
- ⏱️ **No Time Pressure**: Learn at your own pace without stress

### Teacher Mode
- 👩‍🏫 **Create Custom Questions**: Design your own questions for students
- 🏷️ **Topic & Tag Organization**: Categorize questions by topic and add custom tags
- 📝 **Full Question Builder**: Add questions, answers, hints, and explanations
- 💾 **Automatic Saving**: Questions are saved locally in the browser
- 🗑️ **Question Management**: Edit and delete questions as needed

## 🚀 Getting Started

### Running the Application

1. **Using Python (Recommended)**:
   ```bash
   python3 -m http.server 8000
   ```
   Then open your browser to `http://localhost:8000`

2. **Using npm**:
   ```bash
   npm start
   ```
   Then open your browser to `http://localhost:8000`

3. **Direct Opening**:
   Simply open `index.html` in your web browser

## 🎮 How to Use

### For Students
1. Click **"Student Mode"** (default view)
2. Choose a math topic from the colorful grid
3. Read each question carefully - take your time!
4. Use the visual aids to help understand the problem
5. Click **"Need a hint?"** if you get stuck
6. Enter your answer and click **"Check Answer"**
7. Read the explanation to understand the concept
8. Click **"Next Question"** to continue learning

### For Teachers
1. Click **"Teacher Mode"** at the top
2. Fill out the question form:
   - Select a topic/category
   - Add optional tags for organization
   - Write the question
   - Enter the correct answer
   - Provide a helpful hint (optional)
   - Write a clear explanation
3. Click **"Save Question"**
4. Your question will appear in the "Saved Questions" list
5. Students can access custom questions via the "Custom Questions" topic

## 📚 Educational Philosophy

LearnIt is designed with these principles:

- **Understanding > Speed**: No timers, no pressure - just learning
- **Positive Reinforcement**: Every correct answer is celebrated
- **Visual Learning**: Multiple representations help different learning styles
- **Explanation-Driven**: Students learn *why*, not just memorize
- **Repetition without Boredom**: Questions are shuffled for variety
- **Teacher Empowerment**: Easy tools to create custom content

## 🛠️ Technology

- **Pure HTML/CSS/JavaScript**: No frameworks needed, runs anywhere
- **LocalStorage**: Teacher-created questions persist in the browser
- **Responsive Design**: Works on desktop, tablet, and mobile
- **No Backend Required**: Completely client-side application

## 📖 Math Topics Covered

1. **Fractions**: Understanding parts of a whole with visual pizza slices
2. **Addition**: Building number sense with visual blocks
3. **Subtraction**: Taking away with clear examples
4. **Multiplication**: Repeated addition with helpful visuals
5. **Division**: Sharing equally with real-world scenarios
